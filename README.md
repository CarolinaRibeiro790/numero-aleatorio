## 🚀 Sobre o Projeto
Este projeto é um jogo simples de adivinhação de números desenvolvido em JavaScript. O objetivo do jogo é adivinhar o número gerado aleatoriamente pelo programa dentro de 5 tentativas. A cada tentativa, o jogador recebe uma dica indicando se o número digitado é maior ou menor que o número gerado.

## 🛠️ Tecnologias Utilizadas
<li>HTML5: Para a estrutura básica da página.
<li>CSS3: Para estilizar a interface do jogo.
<li>JavaScript: Para gerar o número aleatório, verificar as tentativas e exibir as mensagens.

## 📝 Funcionalidades Principais
1. O número é gerado aleatoriamente pelo JavaScript ao iniciar o jogo.
2. Cada jogador tem 5 chances para adivinhar o número.
3. Após cada tentativa:
 <li>Se o jogador errar, é exibida uma mensagem indicando se o número é maior ou menor.
 <li>Se o jogador acertar, uma mensagem de parabéns é exibida e o jogo é reiniciado. <br>
   
4. Caso o jogador não acerte em 5 tentativas, o jogo mostra o número correto e reinicia automaticamente.
